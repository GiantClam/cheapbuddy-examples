# CheapBuddy 技术群 · 置顶规则（Discord / QQ 通用）

欢迎。这里只聊 **对接、排障、用量与文档**，不聊账号买卖。

## 规则
1. 允许：贴报错原文、curl/日志脱敏、参数对比、成片参数复盘。
2. 禁止：硬广刷屏、「私聊更便宜」「卖号/共享号」、未邀请的站外引流。
3. Key 与账单截图请打码；需要协助时用临时测试 Key。
4. 提问模板：目标（文生/首帧/参考图）→ 请求字段 → 完整错误 JSON → 已试过的步骤。
5. 管理员可移出重复广告与人身攻击。
